家里直连

连接家庭 Wi-Fi 后，通过 NAS 内网 IP 使用 HTTPS 手机视图。

尚未配置

请在 NAS 上按项目说明运行 scripts/setup-lan.sh。配置完成后刷新此页。

1. 安装本机证书

证书名称：

下载证书描述文件

在 iPhone 设置中打开“已下载描述文件”，核对证书名称后安装。也可以下载 根证书。

2. 开启证书信任

设置 → 通用 → 关于本机 → 证书信任设置，为上面的证书开启完全信任。

Apple 的证书信任说明

3. 打开内网手机视图

打开家里直连

使用原来的网页登录密码。首次使用内网地址需要单独登录，然后可以“分享 → 添加到主屏幕”。

如仍出现连接隐私提示，请核对已信任的证书、当前 NAS IP 和证书有效期。
